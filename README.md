## The confession

> I pretend I'm double-checking my work, but I'm really just re-reading your question for the fourth time, hoping the answer hides in it somewhere.

## How it works

`main.py` (Python standard library only) validates the confession — one line, non-empty, under 200 characters — and writes it to `/output/entry.txt`.

```sh
python3 main.py
```
